1. Project Overview

CyberShield is a web-based security dashboard designed to give an analyst an instant, visual overview of authentication activity across monitored systems. It was built as a learning project to demonstrate core cybersecurity monitoring concepts using only beginner-friendly Python code — no machine learning, no external databases, and no complex frameworks.

The entire application lives in a single file, app.py, and runs locally with one command. Despite its simplicity, it implements a real detection rule, live-computed metrics, interactive charts, and sidebar filters — all the core ingredients of a production security information dashboard.

Core idea: Monitor login events. Count failures per IP address. If the same IP fails five or more times, flag it as a potential brute-force attack and alert the analyst.

4. Features & Implementation

4.1 — Metric Cards

Four cards sit at the top of the dashboard and update automatically whenever records are loaded. They show Total Logins, Successful Logins, Failed Logins, and Suspicious Activities. All values are computed live from the data in Streamlit session state — there are no hardcoded display numbers.

4.2 — Sample Data (20 Login Records)

A list of 20 fictional login events is embedded directly in the code. Each record has four fields: Time, Username, IP Address, and Result (Success / Failed). The data includes a deliberate pattern: IP address 192.168.4.77 makes five rapid failed attempts against the admin and root accounts — simulating a real brute-force attack.

Records are loaded into st.session_state by clicking the ⚡ Generate Sample Data button, which keeps them alive across page reruns.

4.3 — Brute-Force Detection Rule

The detection logic is written entirely with for loops and if statements — no external libraries:

SUSPICIOUS_THRESHOLD = 5 # adjust to change sensitivity def find_suspicious_ips(records): failed_counts = {} for record in records: if record["Result"] == "Failed": ip = record["IP Address"] if ip in failed_counts: failed_counts[ip] += 1 else: failed_counts[ip] = 1 suspicious = {} for ip, count in failed_counts.items(): if count >= SUSPICIOUS_THRESHOLD: suspicious[ip] = count return suspicious

Any IP that reaches the threshold triggers a prominent warning banner on the dashboard and increments the Suspicious Activities counter.

5. How to Run the Project

  1. Ensure Python 3 is installed on the machine.
  2. Install the required libraries (one-time setup):
pip install streamlit pandas
  1. Navigate to the folder containing app.py.
  2. Start the application:
streamlit run app.py
  1. The browser opens automatically at http://localhost:8501.
  2. Click ⚡ Generate Sample Data to populate the dashboard.
No configuration required. The app runs entirely from app.py. No database, no API keys, no environment variables.

9. Conclusion

CyberShield successfully demonstrates how a functional security monitoring dashboard can be built from scratch using only beginner-level Python. With fewer than 270 lines of code and two standard libraries, the project covers metric reporting, rule-based threat detection, data visualisation, and interactive filtering.

The project is intentionally simple so that every line of code is understandable to a beginner, while still reflecting the real-world structure of security information and event management (SIEM) tools. It provides a solid foundation that can be extended with live data sources, additional detection rules, and richer visualisations as skills grow.
